# MapLeads - Chrome Web Store Listing

## Extension Name
MapLeads - Google Maps Lead Scraper

## Short Description (132 chars max)
Export Google Maps business leads in one click. Choose fields, download as CSV or JSON. Free: 10 leads. PRO: unlimited.

## Detailed Description
MapLeads exports business leads from any Google Maps search - in one click.

Search for businesses on Google Maps, open MapLeads, pick your fields, and download a clean CSV or JSON file instantly.

FEATURES
- Choose exactly which fields to export: name, category, address, phone, website, rating, reviews, business hours, Google Maps URL
- Auto-scroll to load all results before exporting (up to 600+ businesses)
- Download as CSV (Excel-ready, UTF-8 BOM) or JSON
- Freemium: first 10 leads per scrape free
- PRO ($139 one-time, 1 device): unlimited leads + business hours field

HOW TO USE
1. Go to Google Maps and search for businesses (e.g. "dentists in Austin TX")
2. Click the MapLeads icon in your toolbar
3. Check the fields you want
4. Click "Extract Leads"
5. Your file downloads automatically

USE CASES
- Local lead generation for sales teams and agencies
- Building prospect lists for cold outreach
- Competitive research for local businesses
- Market research and location intelligence

PRIVACY
- No data is sent to any third-party server
- All extraction happens locally in your browser
- No accounts, no tracking, no data collection

## Privacy Practices (Chrome Web Store form)
- Single purpose: Export business leads from Google Maps search results
- Data collected: None. Lead data is extracted and downloaded locally only.
- Remote code: No
- Permissions justification:
  - tabs: Detect if a Google Maps tab is open to inject the scraper
  - scripting: Run the lead extraction script in the Maps page context on user request
  - storage: Persist PRO activation status locally
  - activeTab: Grant temporary access to inject into the active tab on user gesture
  - host_permissions (flowengine.cloud): PRO activation and verification API only
